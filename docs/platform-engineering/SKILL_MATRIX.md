# Platform Engineering Skill Matrix

This document tracks hands-on capability rather than simple tool exposure.

A skill is considered strong only when I can:
1. Understand it
2. Build with it
3. Troubleshoot it
4. Secure it
5. Automate it
6. Explain it without notes

## Evidence Rule

A box should only be changed from ⬜ to ✅ when there is evidence in this repository.

Examples:

- implementation code
- infrastructure configuration
- successful command output
- troubleshooting notes
- incident report
- runbook
- architecture documentation
- monitoring dashboard
- automated test
- CI/CD execution
